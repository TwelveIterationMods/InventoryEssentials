This mod adds various inventory control enhancements that have long established themselves to a be a modded Minecraft standard, such as drag-to-transfer, single-item moves and inventory sorting.

This mod requires [Balm](https://www.curseforge.com/minecraft/mc-mods/balm), which must be installed alongside the mod.

### ![Features](https://mods.twelveiterations.com/img/features-header.png)

*   Control-click an item to only quick-move a single item instead of the entire stack
*   Shift-control click an item to quick-move all stacks of that item type (e.g. all cobblestone from a chest into your inventory)
*   Hold shift and move over items to quick-move them without having to click each individually
*   Hold a mouse button while dragging a bundle to insert or empty items as you pass over them
*   Middle-click in an inventory to sort it (on Minecraft 1.20.1, 1.21.1, and 26.1+)
*   Optional on client and server. Only those who want to use it need to install it, and if the server doesn't have it installed, it will still work for clients who do have it installed.
